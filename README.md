# CIS25_Fall2025
This week’s code includes the required Module 7 tasks:

🔹 1. Binary Search

Implements a function to search for a target value in a sorted array.

Demonstrates divide-and-conquer logic.

Prints whether the number was found and at which index.

🔹 2. Arrays

Shows how to create arrays.

Access elements using indexes.

Loop through an array using for loops.

🔹 3. Pointers

Demonstrates how pointers work in C++.

Uses & to get memory address.

Uses * to dereference pointer values.

All source code files (.cpp) for Week 6 are included in this branch.
Each .cpp file demonstrates different concepts from Module 7.
